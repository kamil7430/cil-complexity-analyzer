# Extracted Codes

This directory contains cleaned up contents of zips in `../zips/` directory. The solutions are categorized by the
laboratory number and the year it was held.

Structure of every laboratory directory:
```
# Common files
Program.cs
Lab??.pdf
# other common files...

# Student solutions
1.cs
2.cs
# other student solutions...
```

The contents are zipped to avoid skewing the GitHub statistics.
