# Archive data directory

This directory contains student solutions and test classes from past years. The data will be analyzed to improve our understanding of:
- which namespaces, classes and methods are used
- what a typical (and atypical) test case looks like
- ...

It will also be the input to test our system against.

A big shout-out to everyone who sent us their files!
